# Lexical Analysis Phase

The **Lexical Analysis** phase is the first stage of the compiler. It reads the input JavaScript source code character by character and converts it into a stream of **tokens** using **Flex**.



---

# Main File

| File      | Purpose                       |
| --------- | ----------------------------- |
| `lexer.l` | Contains token rules for Flex |

---

# Role of Lexer

* Reads raw source code
* Identifies keywords, identifiers, literals, operators, symbols
* Removes whitespace and comments
* Sends tokens to Bison parser

---

# Tokens Recognized

## Keywords

```text id="f3lt8s"
async function const let if return throw new true false
```

Examples:

```text id="a0g8r1"
async   → ASYNC
function → FUNCTION
const   → CONST
```

---

## Operators

```text id="3ad0o9"
=>   ===   ||   -=   =   *   <   >
```

Examples:

```text id="zwp7an"
=>  → ARROW
=== → EQ
-=  → MINUS_ASSIGN
```

---

## Symbols

```text id="m75p5f"
. , ; : ( ) { } [ ]
```

Examples:

```text id="2lwv9v"
( → LPAREN
} → RBRACE
```

---

## Literals

### String Literal

```text id="6xzdgq"
"hello"
```

Returns:

```text id="9qjv7g"
STRING_LIT
```

### Number Literal

```text id="om7quf"
123
```

Returns:

```text id="8ggl8w"
NUMBER_LIT
```

---

## Identifiers

Names of variables/functions:

```text id="2r8jv0"
users
registerUser
fileData
```

Returns:

```text id="s3k5an"
IDENTIFIER
```

---

# Ignored Input

The lexer skips:

```text id="n6o1is"
spaces
tabs
new lines
single-line comments (// ...)
unknown characters
```

---

# Example

Input:

```javascript id="nq8x2x"
const x = 10;
```

Token Stream:

```text id="4ux3ef"
CONST IDENTIFIER ASSIGN NUMBER_LIT SEMICOLON
```

# Summary

The lexical phase converts source code into meaningful tokens for the parser, making syntax analysis possible.
