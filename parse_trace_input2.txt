║           PARSING METHOD: LALR(1)                    ║
╠══════════════════════════════════════════════════════╣
║  Algorithm : LALR(1)  (Look-Ahead LR, 1 token)       ║
║  Generator : GNU Bison                               ║
║  Strategy  : Bottom-up, shift-reduce                 ║
║  Lookahead : 1 token  (decides shift vs reduce)      ║
╠══════════════════════════════════════════════════════╣
║  How it works:                                        ║
║  • SHIFT  – push next token onto the parse stack      ║
║  • REDUCE – pop RHS symbols, push LHS non-terminal   ║
║  • ACCEPT – stack holds start symbol, input is done  ║
║  • 1 lookahead token resolves shift/reduce conflicts  ║
╚══════════════════════════════════════════════════════╝
